CORS note

Why a request may fail from Live Server.

Important

The current Program.cs does not call AddCors or UseCors. A browser page served by Live Server is a different origin, so the API response will be blocked by CORS even when the API is running.

The example settings file already lists allowed origins, but the running application does not read or apply them. The backend must add its existing CORS configuration for the frontend origin to work.

Do not disable browser security to work around this. The frontend cannot fix CORS by itself.
